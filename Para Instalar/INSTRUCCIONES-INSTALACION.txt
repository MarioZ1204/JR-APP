================================================================================
  JR — Sistema de restaurante (POS local)
  Instrucciones de instalación
  Versión 1.1.0
================================================================================

Este documento explica qué debe llevar la carpeta y cómo instalarla en el PC
del restaurante.


--------------------------------------------------------------------------------
1. REQUISITOS DEL PC DEL RESTAURANTE
--------------------------------------------------------------------------------

  • Windows 10 u 11 (64 bits recomendado)
  • Node.js versión 22 o superior (LTS desde https://nodejs.org)
    Comprobar en CMD o PowerShell:  node -v
  • Conexión WiFi/LAN en el local (tablets y celulares en la misma red)
  • Navegador: Chrome o Edge (actualizado)

  NO se necesita:
  • XAMPP, MySQL, Apache ni hosting en internet
  • Instalar SQLite por separado (viene integrado en Node.js 22+)


--------------------------------------------------------------------------------
2. QUÉ ARCHIVOS DEBE TENER LA CARPETA
--------------------------------------------------------------------------------

  JR-APP/
  ├── iniciar.bat              ← Uso diario
  ├── instalar.bat             ← Solo la primera vez
  ├── permitir-red.bat         ← Si celulares no entran (firewall)
  ├── package.json
  ├── package-lock.json
  ├── server/
  ├── public/
  ├── scripts/
  ├── docs/
  ├── README.md
  └── INSTRUCCIONES-INSTALACION.txt

  Se crean solas al arrancar:
  ├── node_modules/
  ├── data/                    ← Base de datos
  └── backups/


--------------------------------------------------------------------------------
3. ¿LA BASE DE DATOS SE CREA SOLA?
--------------------------------------------------------------------------------

  SÍ. Al ejecutar iniciar.bat (o npm start) por primera vez:

  1. Se crea data/restaurante.db
  2. Se crean tablas y datos iniciales (usuarios, mesas, menú demo)
  3. Se guarda un respaldo diario en backups/

  Para respaldar: copie data/restaurante.db o la carpeta backups/ a un USB.


--------------------------------------------------------------------------------
4. INSTALACIÓN EN EL PC DEL RESTAURANTE
--------------------------------------------------------------------------------

  LUGAR RECOMENDADO:  C:\JR-Sistema
  NO use: C:\Program Files\...  (Windows bloquea guardar la base de datos ahi)

  1. Instale Node.js 22+ si no lo tiene
  2. Copie la carpeta "Para Instalar" a C:\JR-Sistema
  3. Doble clic en instalar.bat
     • Instala dependencias
     • Pregunta si dejar el sistema limpio (recomendado: Sí)
     • Crea acceso directo "JR Sistema" en el escritorio
  4. Use JR Sistema.exe, iniciar.bat o el acceso directo
  5. Entre con admin / admin123 y cambie la contraseña
  6. En Ajustes: NIT, impresora, mesas, personal

  Si ya lo puso en Archivos de programa:
  • Ejecute instalar.bat como administrador la primera vez, o
  • Mueva la carpeta a C:\JR-Sistema (recomendado)
  • Los datos pueden quedar en:
    %LOCALAPPDATA%\JR-Burger\data


--------------------------------------------------------------------------------
5. USO DIARIO
--------------------------------------------------------------------------------

  ARRANCAR
  • Doble clic en iniciar.bat — deje la ventana ABIERTA
  • Se abre http://localhost:3000

  TABLETS / CELULARES
  • Use la IP que muestra la consola, ej. http://192.168.0.104:3000
  • Misma WiFi (no datos móviles)
  • Si no entra: permitir-red.bat como administrador

  TAILSCALE (entrar desde fuera del local o con datos móviles)
  • Cuenta: jrburgerpasto@gmail.com
  • En el PC: doble clic en conectar-tailscale.bat e inicie sesión con esa cuenta
  • En el celular: instale Tailscale e inicie sesión con la misma cuenta
  • Arranque el sistema; verá una dirección tipo http://100.x.x.x:3000
  • Si no carga, ejecute permitir-red.bat una vez

  APAGAR
  • Cierre caja si hay turno abierto
  • Cierre la ventana de iniciar.bat / JR Sistema.exe o Ctrl+C

--------------------------------------------------------------------------------
7. COMANDOS ÚTILES
--------------------------------------------------------------------------------

  npm install     Instalar dependencias
  npm start       Iniciar servidor
  npm run backup  Copia manual de la base de datos
  npm test        Prueba automática


--------------------------------------------------------------------------------
8. SOLUCIÓN DE PROBLEMAS
--------------------------------------------------------------------------------

  "No se encontró Node.js"
  → Instale Node.js 22+ desde https://nodejs.org

  "Cannot find module 'express'"
  → Ejecute npm install o iniciar.bat

  El celular no abre la página
  → Misma WiFi, IP con :3000, permitir-red.bat

  Pantalla en blanco
  → Ctrl+F5 en el navegador

  Impresora
  → Ver docs/IMPRESORA.md


--------------------------------------------------------------------------------
9. RESUMEN
--------------------------------------------------------------------------------

  Primera vez:  instalar.bat → iniciar.bat → admin → cambiar clave → configurar
  Cada día:     iniciar.bat
  Base datos:   se crea sola en data/restaurante.db
  Internet:     no obligatorio (solo red local)
